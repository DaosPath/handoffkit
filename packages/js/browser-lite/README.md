# @handoffkit/browser-lite

HTTP search, fetch, HTML→Markdown, and opt-in project index helpers for
HandoffKit 1.20. This package does not launch Chromium or import
`@handoffkit/browser-real`.

The implementation currently lives in `@handoffkit/browser` and is re-exported
here as the named Lite product. `@handoffkit/browser` remains the compatibility
facade.
