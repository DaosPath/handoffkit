# HandoffKit 1.20 - Browser Platform (absorbs 1.20-1.29)

Status: **beta implementation in progress**. This range is a single 1.20 train.
The older [1.20-1.29 plan](./1.20-1.29-BROWSER-PLATFORM.md) is retained as
history and is not the active split.

A dimension must score at least 9/10 on real binary gates. There is no average.
Until every dimension is >=9, 1.20 remains beta. See
[`reports/BROWSER_1.20_SCORECARD.md`](../../reports/BROWSER_1.20_SCORECARD.md).

## Products

- `@handoffkit/browser-core` - I/O-free contracts (`1.20.0-alpha.1`)
- `@handoffkit/browser` - Lite compatibility facade; never imports Real
- `@handoffkit/browser-lite` - named Lite product (re-export)
- `@handoffkit/browser-real` - supervised Playwright/Chromium service, Node 24+,
  Chromium only via `pnpm --dir js/packages/browser-real run install-chromium`

Python, Rust, Go, and C++ ship matching Core models. Hermes is a client.
