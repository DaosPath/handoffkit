## Current classification

Errata for the rows above: the current tree now includes C++ OpenSSL OCSP
response validation, provider-gated macOS/Linux keystore backends, C++
`SecureBuffer` use in `ArtifactSigner`, C++ `DurableScheduler`, and the common
TLS `CspDispatcher`. These are scoped/provider-dependent controls, not global
guarantees. Exactly-once external effects, OCSP responder discovery/fetch,
global zeroization, non-Linux ARM64 breadth, and remote benchmark archives
remain unavailable until their execution evidence exists.

Stable: bounded framing/envelope validation, local stdio/subprocess transport,
and business deduplication within their documented scope. Experimental/near-
stable: the integrated TLS, identity, replay, authorization, transcript,
artifact, durable scheduler, native worker, edge, Studio, conformance, and
benchmark rows above. Provider-dependent: compatible Node/Go `hybrid-pq` only.
Unavailable: OCSP, global zeroization, Python/Rust/C++ `hybrid-pq`, and
non-Ed25519 signature algorithms. C++ Windows keystore, scoped native
zeroization, C++ TLS, and file-CRL checking are
provider-dependent experimental paths, not universal C++ security coverage.
