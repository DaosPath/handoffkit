## Explicit unavailable claims

- Exactly-once external effects: unavailable. Durable files cannot atomically
  include arbitrary external side effects; the C++ API refuses silent fallback.
- Global zeroization: unavailable. Native scoped buffers do not cover allocator
  copies, provider internals, `std::string` returns, or managed runtimes.
- OCSP responder fetch (AIA/HTTP/HTTPS) remains unavailable in every runtime;
  Python/JavaScript/Go/Rust reject active OCSP configuration with
  `ocsp_fetch_unavailable`, while C++ only validates configured signed
  response files and rejects `ocsp_fetch=true`/responder URLs.
- ML-DSA/ECDSA/SLH-DSA signatures: unavailable without maintained provider and
  vectors; unsupported wire algorithms return structured
  `artifact_algorithm_unsupported` errors.
- C++/Python/Rust hybrid-PQ: unavailable; capability detection is false and
  profile selection fails closed.
- Remote benchmark results: available for the hosted Linux x86_64 environment
  in run [31341281693](https://github.com/DaosPath/handoffkit/actions/runs/31341281693)
  and artifact `handoffkit-security-benchmarks-31341281693`. The measurements
  carry the required environmental notice and are not performance guarantees.
